# Règles propres au projet

Un fichier `.md` par règle. Elles sont chargées au début de chaque session
Claude Code par le plugin `bza` (ce README est ignoré).

Une règle de projet **complète** les lois, elle ne les contredit
jamais. Écrire une règle courte, vérifiable, avec son motif : une règle sans
motif ne se lève jamais.
