# `2026-11-19` — « Mes logements » : le statut en pastille de couleur

- **Question posée** : « dans mes logements ajouter le statut à la card comme dans mes réservations ».

- **Motif** : la demande de l'humain.
- **Portée** : `OfferStatusEnum::tone()`, `OfferListing` ; rien dans l'app (pastille générique).
- **Corollaires** : aucun.
