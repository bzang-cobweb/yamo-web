# `2026-11-24` — Formulaire d'un partenaire : l'étape « Présentation »

- **Type** : décision
- **Question posée** : « étape partenaire renommer en présentation ».
- **Réponse** : la demande elle-même.
- **Ce qui est retenu** : dans l'app, l'étape du logo, du nom et de la description s'appelle « Présentation » (« Presentation », « Präsentation ») ; l'onglet « Partenaire » du back-office garde son nom.
- **Motif** : la demande de l'humain.
- **Portée** : `PartnerForm` de l'app ; texte `partner::partner.member.steps.presentation`.
- **Corollaires** : aucun.
- **Tranché par** : humain
