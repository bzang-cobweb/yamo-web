# Listes : un écart plus grand entre deux cartes

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active

## Décision
Dans toutes les listes de cartes de l'app, l'écart entre deux cartes passe de 8 à 16 points
(`Spacing.three`). Ces listes sont l'accueil, les favoris, « Mes logements », « Mes
réservations », « Réservations reçues », les adresses et les notifications. Elles passent toutes
par le composant `List`, dont le séparateur porte cet écart.

## Motif
Demande de l'humain du 2026-11-21 : « augmenter l'écart entre 2 cards dans toutes les listes des
cards ».
