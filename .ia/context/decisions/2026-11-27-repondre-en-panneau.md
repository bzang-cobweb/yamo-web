# `2026-11-27` — Page d'une notification : les formulaires dans un panneau à leur hauteur

Complète : 2026-11-26-formulaires-en-panneau.md, 2026-11-26-message-editeur-en-panneau.md

- **Type** : décision
- **Question posée** : « page detail notification de type message clique sur le bouton répondre ouvre le formulaire sur un panneau avec sa hauteur ».
- **Ce qui est retenu** : sur la page d'une notification, le panneau d'un formulaire (« Répondre » d'un message, mais aussi « Modifier », « Annuler », « Inviter à donner un avis » d'une demande) prend la hauteur du formulaire (`fitContent`), comme sur la fiche d'une offre ; un formulaire plus long que l'écran va jusqu'à la taille maximale et défile.
- **Tranché par** : humain
