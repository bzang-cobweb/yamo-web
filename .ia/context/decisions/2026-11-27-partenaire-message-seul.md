# `2026-11-27` — Un membre seul peut écrire dans le fil de son partenaire

Remplace en partie : 2026-11-27-partenaire-messages.md (il fallait un autre membre)

- **Type** : décision
- **Question posée** : « est-ce qu'on pourrait écrire même si un seul membre ? » ; proposition acceptée : « oui fais-le ».
- **Ce qui est retenu** : tout compte rattaché au partenaire peut écrire, même seul membre. Sans autre membre pour le recevoir, le message est gardé chez son auteur : dans l'onglet seulement (ni e-mail ni SMS), déjà lu, dans le fil du partenaire, où un membre ajouté plus tard le lit. Avec un autre membre, rien ne change.
- **Tranché par** : humain
