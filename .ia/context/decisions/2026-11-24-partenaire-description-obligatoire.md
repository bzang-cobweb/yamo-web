# `2026-11-24` — Partenaire : la description obligatoire, le logo facultatif

- **Type** : décision
- **Question posée** : « la description d'un partenaire est obligatoire pas le logo ».
- **Réponse** : la demande elle-même.
- **Ce qui est retenu** : la description est obligatoire, dans l'app (formulaire `partner.partner`, à la création comme à la modification, dans la langue saisie) et au back-office (dans la langue par défaut, comme le nom) ; le logo reste facultatif.
- **Motif** : la demande de l'humain.
- **Portée** : `PartnerForm` de l'app et du back-office.
- **Corollaires** : un partenaire existant sans description devra en recevoir une à sa prochaine modification.
- **Tranché par** : humain
