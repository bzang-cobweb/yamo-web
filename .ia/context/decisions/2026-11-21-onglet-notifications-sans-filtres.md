# Toucher l'onglet Notifications enlève tous les filtres

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active
- **Complète** : 2026-11-20-filtres-notifications.md, 2026-11-20-compteur-vers-notifications.md

## Décision

Toucher « Notifications » dans le menu du bas enlève tous les filtres choisis de la liste des
notifications (`clearFilters`) : la liste revient complète. La recherche saisie n'est pas
touchée. Un compteur « x demandes en attente » qui ouvre les notifications déjà filtrées ne
passe pas par l'onglet : ses filtres restent.

## Motif

Demande de l'humain du 2026-11-21 : « quand on clique sur notifications menu footer du bas on
enlève tous les filtres ». Recherche laissée telle quelle : décidé seul.
