# `2026-11-23` — Accueil : le texte des cartes sans retrait

- **Type** : décision
- **Question posée** : « les cards de l'accueil n'ont pas de décalage pour la zone de contenu donc occupe la même largeur que les photos ».
- **Réponse** : la demande elle-même.
- **Ce qui est retenu** : sur l'accueil, la zone de texte d'une carte n'a plus de retrait de côté ; elle a la largeur de la photo. La recherche garde son retrait (décision 2026-11-22-cartes-espace-sous-photo).
- **Motif** : la demande de l'humain.
- **Portée** : `OfferCard` (`compact`).
- **Corollaires** : aucun.
- **Tranché par** : humain
