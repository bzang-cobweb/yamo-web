# Formulaires du profil : le sous-titre en style de titre dans la zone de contenu

- **Date** : 2026-11-22
- **Type** : décision
- **Décidé par** : l'humain (« garder le titre de l'offre dans la zone de contenu et l'appliquer le style de titre »)

## Décision

Dans un formulaire ouvert depuis le profil, le titre (« Réserver », « Demander une visite », « Modifier la
demande ») reste dans la barre du haut, et le sous-titre — le titre de l'offre pour une demande — s'affiche en
tête du contenu avec le style de titre (au lieu du gris).

## Portée

App : `DynamicForm` ; vaut pour tout formulaire dont le titre est dans la barre et qui a un sous-titre (aussi
« Répondre » et « Refuser la demande »). Ailleurs (titre dans le contenu), le sous-titre reste gris dessous.
