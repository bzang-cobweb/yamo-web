# Demande modifiée : « Vous avez reçu une demande de séjour / de visite modifiée »

- **Date** : 2026-11-22
- **Type** : décision
- **Demandé par** : l'humain (« Oui, aussi », pour la demande modifiée)
- **Complète** : 2026-11-22-nouvelle-demande-recue.md

## Décision

Sur la carte du propriétaire, le texte d'une demande modifiée devient « Vous avez reçu une demande de séjour modifiée pour « :offer » (:period, :people). », et pour une visite « … une demande de visite modifiée pour « :offer » (:period). ». En anglais : « You received a changed … request for … ». En allemand : « Sie haben eine geänderte …anfrage für … erhalten. ».

## Portée

Seulement `updated.summary` et `summary_stay`. Les notifications enregistrées ont été réécrites en local.
