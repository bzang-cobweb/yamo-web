# `2026-11-25` — Le titre d'une offre : 50 caractères au plus, 255 en base

- **Type** : décision
- **Question posée** : « limiter titre offre à 50 caractères max laisser 255 en base de données ».
- **Ce qui est retenu** :
  - `Offer::TITLE_MAX_LENGTH = 50`, appliqué au formulaire de l'app (`OfferForm`, validation comprise) et à celui du back-office, dans chaque langue.
  - La colonne garde sa taille : aucune migration. Les titres plus longs déjà enregistrés restent ; on ne peut les réenregistrer qu'en les raccourcissant.
- **Motif** : comme le nom d'un partenaire (décision 2026-11-24-partenaire-nom-slogan-50), un titre court tient sur les cartes.
- **Portée** : la saisie du titre d'une offre.
- **Tranché par** : humain
