# Mes logements : « Demandes reçues » dans le menu ⋮

- **Date** : 2026-11-22
- **Type** : décision
- **Décidé par** : l'humain (« mettre demandes reçues dans le dropdown dans mes logements »)

## Décision

L'entrée du menu ⋮ d'une carte de « Mes logements » qui ouvre les demandes du logement s'appelle « Demandes
reçues » (au lieu de « Demandes ») ; en : « Requests received », de : « Erhaltene Anfragen ».

## Portée

Clé `offer::booking.profile.notifications`, utilisée seulement par cette entrée.
