# « Mes réservations » : la ville remise sur la ligne du type

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active
- **Complète** : 2026-11-21-reservations-type-de-location-titre.md, 2026-11-21-reservations-titres-inverses-sans-prix.md

## Décision
Sur une carte de « Mes réservations », la ligne sous le titre saisi redevient type de location,
type de logement et ville : « Location meublée · Studio · Douala ». Sans adresse, la ville est omise.

## Motif
Demande de l'humain du 2026-11-21 : « remettre la ville », après l'inversion des deux titres.
