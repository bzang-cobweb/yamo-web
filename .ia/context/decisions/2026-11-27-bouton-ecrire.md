# `2026-11-27` — Le bouton d'un fil de messages : « Écrire »

- **Type** : décision
- **Question posée** : « remplacer le label du bouton répondre par écrire ».
- **Ce qui est retenu** : sur la page d'une notification de message, le bouton du bas s'appelle « Écrire » (en : « Write », de : « Schreiben ») au lieu de « Répondre ». Le libellé est relu à l'affichage (`AddOfferToMessageThread`), dans la langue du lecteur : les messages déjà reçus montrent aussi « Écrire ».
- **Tranché par** : humain
