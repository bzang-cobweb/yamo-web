# `2026-11-25` — « Voir tous les 3 avis »

- **Type** : décision
- **Question posée** : « voir tous les x avis ».
- **Ce qui est retenu** : sur la fiche d'une offre, le bouton qui ouvre la liste complète donne le nombre d'avis : « Voir tous les 3 avis » (en « See all 3 reviews », de « Alle 3 Bewertungen ansehen »). Le nombre est le total des avis de l'offre, pas seulement ceux du carrousel.
- **Tranché par** : humain
