# `2026-11-27` — Fiche d'une offre : « Voir plus » ouvre la description dans un panneau

Complète : 2026-11-22-description-voir-plus.md, 2026-11-26-lignes-en-panneau.md

- **Type** : décision
- **Question posée** : « page de detail offre, le click sur voir plus de description ouvre la description dans panneau ».
- **Ce qui est retenu** : une description de plus de quatre lignes reste repliée sur la fiche ; « Voir plus » ouvre le texte entier dans un `BottomSheet` à la hauteur du texte, titré de la section (« Description »), qui défile s'il dépasse la taille maximale. La croix ou le fond le ferment.
- **Corollaire** : « Voir moins » disparaît (clé `offer.less` retirée).
- **Tranché par** : humain
