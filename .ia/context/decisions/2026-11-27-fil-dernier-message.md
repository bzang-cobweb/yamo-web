# `2026-11-27` — La page d'une notification s'ouvre sur le dernier message du fil

- **Type** : décision
- **Question posée** : « quand on ouvre le détail d'une notification, toujours se positionner au niveau du dernier message dans le fil ».
- **Ce qui est retenu** : la page d'une notification défile jusqu'au dernier message du fil à l'ouverture (sans animation) et à chaque nouveau message (animé, après un envoi) ; tant que le lecteur n'a pas remonté le fil lui-même, elle suit le contenu qui grandit. Un lecteur qui remonte n'est pas ramené en bas, sauf quand un nouveau message arrive.
- **Tranché par** : humain
