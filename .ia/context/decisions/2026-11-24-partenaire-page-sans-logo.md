# `2026-11-24` — Page d'un partenaire : sans logo, pas de cadre

- **Type** : décision
- **Question posée** : « ne pas afficher le logo si vide page de détail ».
- **Réponse** : la demande elle-même.
- **Ce qui est retenu** : sur la page d'un partenaire, un partenaire sans logo n'a ni cadre ni nom à sa place : la page commence par son nom. Sur l'accueil et dans les listes, le cadre avec le nom reste (décision 2026-11-23-partenaires-logos).
- **Motif** : la demande de l'humain ; le nom est déjà le titre de la page.
- **Portée** : `PartnerDetailScreen` de l'app.
- **Corollaires** : aucun.
- **Tranché par** : humain
