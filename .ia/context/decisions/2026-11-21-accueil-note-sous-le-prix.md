# Cartes : la note sous le prix, sur sa ligne, à droite

- **Date** : 2026-11-21
- **Type** : décision
- **Décidé par** : l'humain (« cards accueil mettre la note après le prix aligné à droite » → « Oui, ligne à
  part » ; « le faire aussi sur mes réservations, mes favoris et sur mes logements »)

## Décision

Sur les cartes, les étoiles de la note ne sont plus sur la ligne du prix : elles passent sur leur propre ligne,
sous le prix, alignées à droite. Accueil, Mes réservations, favoris, Mes logements — toutes les listes qui
servent une note.

## Portée

App : `ItemReviews` (partagé par l'accueil et les listes du profil).
