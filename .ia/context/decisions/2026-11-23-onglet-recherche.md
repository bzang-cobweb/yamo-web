# `2026-11-23` — App : un onglet « Recherche », l'accueil vidé

- **Type** : décision
- **Question posée** : « ajouter un menu avec une icone search avant les notifications / déplacer tout ce qu'il y a dans l'accueil sur ce menu search ».
- **Réponse** : la demande elle-même.
- **Ce qui est retenu** :
  - menu du bas : Accueil, Recherche (loupe), Notifications, Profil ;
  - l'onglet « Recherche » (`/search`) montre ce qu'affichait l'accueil : les offres du pays, la recherche et les filtres (`BrowseScreen`) ;
  - l'accueil (`/`) reste l'écran par défaut, vide pour l'instant ;
  - « Rechercher un logement », en bas de « Mes réservations » et des favoris, ouvre l'onglet « Recherche » ;
  - l'écran d'un visiteur non connecté ne change pas.
- **Motif** : la demande de l'humain.
- **Portée** : onglets de l'app, `ProfileListScreen`, `BookingListing`, `OfferFavoritesListing`, textes `tabs.search` (fr, en, de).
- **Corollaires** : le contenu de l'accueil reste à définir.
- **Tranché par** : humain
