# « Mes réservations » : la ville sur la ligne du type

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active
- **Complète** : 2026-11-21-reservations-titres-inverses-sans-prix.md

## Décision
Sur une carte de « Mes réservations » :
- le titre est le titre saisi de l'offre ;
- la ligne en dessous est « Location meublée · Studio · Douala » (`RentalDomain::bookingItemTitle`) ;
- viennent ensuite le type de demande et les dates.

Sans adresse, la ville est omise.

## Motif
Demande de l'humain du 2026-11-21. L'humain avait demandé « remettre la ville sur le titre » ; on
lui a demandé si le titre en gras était le bon. Sa réponse : « Non, sur la ligne du type ».
