# `2026-11-27` — Fiche d'un partenaire : une ligne « Membres » dans le tableau

- **Type** : décision
- **Question posée** : « ajouter une ligne membres dans le tableau » (la fiche d'un partenaire).
- **Ce qui est retenu** : dans le tableau de la fiche (`PartnerDetails` : « E-mail », « Téléphone »), une ligne « Membres » avec le nombre de ses comptes, après le téléphone. Elle n'existe que pour ses comptes : les membres ne sont servis qu'à eux (décision 2026-11-27-partenaire-membres). La valeur est un texte, pas un lien : la liste des membres s'ouvre par le menu (« Membres »).
- **Portée** : mobile, `PartnerDetails` : la page d'un partenaire et le panneau « Info » d'une notification de partenaire.
- **Tranché par** : humain
