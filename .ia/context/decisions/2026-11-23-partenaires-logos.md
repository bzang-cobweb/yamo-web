# `2026-11-23` — Accueil : les partenaires en carrousel de logos

- **Type** : décision
- **Question posée** : « faire un carousel pour les partenaires normalement le logo et le lien sont suffisants », « si pas de logo afficher le nom centré dans un cadre fond gris », puis « enlever le fond gris sur cards partenaires de l'accueil ».
- **Réponse** : les demandes elles-mêmes.
- **Ce qui est retenu** :
  - en bas de l'accueil, le titre « Partenaires » puis un carrousel de logos seuls, dans un cadre ; toucher un logo compte un clic et ouvre le lien ;
  - sans logo, le nom centré dans le cadre, sans fond ;
  - le nom est lu par les lecteurs d'écran ; la description et le libellé du bouton restent au back-office et dans l'API, l'app ne les affiche pas.
- **Motif** : les demandes de l'humain.
- **Portée** : `PartnersStrip` de l'app.
- **Corollaires** : aucun changement d'API.
