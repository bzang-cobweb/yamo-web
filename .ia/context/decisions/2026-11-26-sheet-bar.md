# `2026-11-26` — `SheetBar`, la barre du bas d'un panneau ; un panneau de même largeur partout

- **Type** : décision
- **Question posée** : « faire le SheetBar, et quel est le meilleur choix ? limiter les deux ou les deux sur toute la largeur ? le but c'est d'avoir la même chose ».
- **Ce qui est retenu** :
  - `SheetBar` (`mobile/src/shared/components/`) : la barre fixe du bas d'un panneau, bordée en haut, sur le fond du thème, 16 de marge sur les côtés et 12 en haut et en bas ; `row` : ses éléments sur une ligne, aux deux bouts (les filtres) ; sinon en colonne (la note et l'action d'un jour du calendrier) ; le contenu la place après ce qui défile ;
  - la largeur est réglée dans `BottomSheet`, pour tout panneau : sur un écran d'au moins 600 points (`SHEET_COLUMN_FROM` : tablette, web), tout le panneau (titre, contenu, barre) est une colonne centrée de `MaxContentWidth / 2` (400) ; en dessous (un téléphone), toute la largeur ;
  - le rendu sur téléphone ne change pas (une limite de 400 sur un écran de 402 laissait un liseré d'un point de chaque côté : d'où le seuil).
- **Motif** : les deux panneaux ont le même rendu hors de leur contenu ; un style de barre écrit une fois.
- **Portée** : les panneaux qui montent du bas (app) ; la page plein écran des filtres utilise aussi `SheetBar`.
- **Tranché par** : humain (le `SheetBar`, la même chose pour les deux) ; session (la largeur limitée dans `BottomSheet`, le seuil de 600)
