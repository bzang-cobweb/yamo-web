# « Location longue durée » devient « Location »

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active
- **Complète** : 2026-11-20-contrat-type-de-location.md

## Décision
Le libellé du type de location `long_term` devient « Location » (en : « Rental », de :
« Miete »), partout où il s'affiche : formulaire de l'offre, fiche, filtres, cartes. La valeur
`long_term` ne change pas.

## Motif
Demande de l'humain du 2026-11-21 : « renommer location longue durée par Location ».

## Portée
Les libellés seulement. Les noms de catégories ne changent pas.
