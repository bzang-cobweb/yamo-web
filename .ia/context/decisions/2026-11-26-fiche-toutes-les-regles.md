# `2026-11-26` — La fiche montre toutes les catégories de règles

- **Type** : décision
- **Question posée** : « page détail offre : afficher les catégories des règles ».
- **Ce qui est retenu** : dans la section « Règles » de la fiche, chaque sous-catégorie de « Règles » a sa ligne : « Oui » si la case est cochée, sinon « Non ». Avant, seules les cases cochées apparaissaient. Une règle ajoutée au back-office apparaît d'elle-même. Les équipements, eux, restent sur une ligne, seulement les cochés.
- **Conséquence** : toute offre a désormais une section « Règles », au moins avec ces lignes à « Non ».
- **Tranché par** : humain ; session (« Non » pour une case pas cochée)
