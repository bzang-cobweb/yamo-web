# Types de notification : « de logement »

- **Date** : 2026-11-22
- **Type** : décision
- **Demandé par** : l'humain (« mettre de logement dans les types de notifications »)

## Décision
Les types (`offer::booking.notify.types`) sont :
- « Nouvelle demande de logement » ;
- « Demande de logement envoyée » (la copie de sa propre demande) ;
- « Demande de logement modifiée » ;
- « Demande de logement acceptée » ;
- « Demande de logement refusée » ;
- « Demande de logement annulée ».

Ils sont aussi traduits en en et de.

Les libellés du suivi, sur le détail (« Demande acceptée »), ne changent pas.
