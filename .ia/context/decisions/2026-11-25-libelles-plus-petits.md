# `2026-11-25` — Les libellés des champs de formulaire plus petits

- **Type** : décision
- **Question posée** : « diminuer la taille de police pour les labels des formulaires ».
- **Ce qui est retenu** : le libellé d'un champ passe de 14 à 13 points (interligne 18), toujours en gras, dans tous les formulaires de l'app et les filtres. C'est le gabarit commun des champs (`FieldShell`). Le texte saisi, l'aide et les erreurs gardent leur taille.
- **Tranché par** : humain (plus petit) ; session (13 points, partout)
