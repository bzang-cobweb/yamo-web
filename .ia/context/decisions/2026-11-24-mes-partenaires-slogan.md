# `2026-11-24` — « Mes partenaires » : le slogan sous le nom

- **Type** : décision
- **Question posée** : « mes partners cards affiche le slogan en dessous du titre, autrement on garde la description », puis « faire pareil sur la page partenaires ».
- **Réponse** : la demande elle-même.
- **Ce qui est retenu** : sur les cartes de « Mes partenaires » et de la page « Partenaires », la ligne sous le nom est le slogan ; sans slogan, la description (`Partner::cardLine()`) ; sur une ligne dans « Mes partenaires ».
- **Motif** : la demande de l'humain.
- **Portée** : `Partner::cardLine()`, `MyPartnerListing`, `PartnerListing`.
- **Corollaires** : la page d'un partenaire montre toujours les deux, le slogan sous le nom et la description plus bas.
- **Tranché par** : humain
