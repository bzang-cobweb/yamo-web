# Calendrier d'un logement : le nom du membre sans lien

- **Date** : 2026-11-22
- **Type** : décision
- **Demandé par** : l'humain (« enlever le lien sur le membre dans cards calendrier »)
- **Complète** : 2026-11-22-calendrier-carte-demandes-recues.md

## Décision

Sur les cartes du panneau du jour, le nom du membre n'est plus un lien vers sa page : c'est du texte en gras. Toucher la carte ouvre toujours la page de la demande. La liste des demandes reçues garde le lien.

## Portée

`OfferCalendar::cards` sert l'item avec `titleLink(null)`.
