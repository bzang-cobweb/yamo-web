# Le titre de l'offre dans le formulaire de réservation

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active

## Décision

Sous le titre du formulaire de réservation ou de visite (« Réserver », « Demander une visite »),
le sous-titre est le titre de l'offre tel que saisi (« Studio meublé à Bonanjo »), et non plus le
titre construit par le domaine (« Studio · meublé · Douala »).

## Motif

Demande de l'humain du 2026-11-21 : « dans le formulaire de réservation mettre le titre de
l'offre ». Remplacement du titre construit (plutôt qu'un ajout) : décidé seul.
