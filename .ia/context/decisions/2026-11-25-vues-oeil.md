# `2026-11-25` — Les vues : un œil suivi du nombre

- **Type** : décision
- **Question posée** : « mes partenaires cards mettre icon oeil suivi du nombre de vues ; pareil pour détail partenaire et déplacer après le slogan ».
- **Ce qui est retenu** :
  - Les vues s'affichent en gris : un œil suivi du nombre (« 👁 12 »). Les lecteurs d'écran lisent « 12 vues ». Le composant est `ViewsCount`, côté app.
  - L'API sert `views: {count, label}`, à deux endroits :
    - sur un item de liste (`ListItem::views()`), à la place de la ligne `detail` ;
    - sur la page d'un partenaire, pour ses comptes.
  - **Cartes** : l'œil est sous le sous-titre, sur les cartes de « Mes partenaires » et aussi sur celles de « Mes logements », pour garder les deux pareilles.
  - **Page d'un partenaire** : l'œil est centré juste après le slogan, sous le nom s'il n'a pas de slogan. Il n'est plus avant la description.
  - Une réponse d'une autre forme n'affiche rien plutôt que de casser l'écran, par exemple l'ancienne chaîne « 21 vues » gardée en cache.
- **Remplace** : la ligne « 12 vues » de 2026-11-25-compteurs-offres et la place de 2026-11-25-partenaire-vues-sur-sa-page.
- **Tranché par** : humain (l'œil, la place) ; session (« Mes logements » suit, le gris)
