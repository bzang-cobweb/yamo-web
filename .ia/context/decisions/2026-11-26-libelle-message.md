# `2026-11-26` — Le champ du message d'une demande s'appelle « Message »

- **Type** : décision
- **Question posée** : « renommer "message au propriétaire" par "message" ».
- **Ce qui est retenu** : le champ du message, dans les formulaires de demande (réserver, demander une visite, modifier) et d'annulation, s'intitule « Message » (en : « Message », de : « Nachricht ») au lieu de « Message au propriétaire ». Les textes d'aide (« Expliquez pourquoi vous annulez (facultatif)… ») ne changent pas.
- **Motif** : le destinataire va de soi dans une demande ; le libellé court suffit.
- **Tranché par** : humain
