# `2026-11-27` — Modifier un partenaire : le bouton « Enregistrer »

- **Type** : décision
- **Question posée** : « formulaire d'édition partenaire remplacer le submit label par enregistrer ».
- **Ce qui est retenu** : le bouton d'envoi du formulaire de modification d'un partenaire s'appelle « Enregistrer » (en : « Save », de : « Speichern ») au lieu de « Enregistrer et renvoyer ». L'ajout garde « Envoyer pour validation » ; le message après l'envoi dit toujours que l'équipe revalide le partenaire.
- **Tranché par** : humain
