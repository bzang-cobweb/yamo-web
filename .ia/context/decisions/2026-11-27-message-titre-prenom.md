# `2026-11-27` — Le panneau d'un message titré du prénom du destinataire

Complète : 2026-11-26-message-editeur-en-panneau.md, 2026-11-27-message-sans-prenom.md

- **Type** : décision
- **Question posée** : « dans le formulaire envoyer un message depuis la fiche, mettre le prénom de l'utilisateur à la place du titre ».
- **Ce qui est retenu** : le titre du formulaire `offer.message`, qui est celui de son panneau, est le prénom de qui va lire le message : l'éditeur de l'offre quand un membre lui écrit depuis la fiche, le membre quand l'éditeur lui répond ; sans prénom, « Envoyer un message ». Rien au-dessus du champ (décision 2026-11-27-message-sans-prenom).
- **Tranché par** : humain
