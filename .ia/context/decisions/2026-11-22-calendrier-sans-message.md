# Calendrier d'un logement : pas de message sur les cartes

- **Date** : 2026-11-22
- **Type** : décision
- **Demandé par** : l'humain (« enlever le message sur les cards calendrier »)
- **Complète** : 2026-11-22-calendrier-carte-demandes-recues.md

## Décision

Les cartes du panneau du jour n'affichent plus le dernier message de la demande. Il reste sur la page de la demande et dans la liste des demandes reçues. Une carte du calendrier se lit ainsi : statut, nom du membre, type et dates, date, puis « Accepter » et « Refuser » tant qu'elle attend.

## Portée

`OfferCalendar::cards` sert l'item avec `quote(null)`.
