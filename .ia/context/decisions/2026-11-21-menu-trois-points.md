# Le menu des actions s'ouvre par trois petits points

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active
- **Complète** : 2026-11-21-actions-en-menu.md

## Décision

Sur les cartes d'une liste à menu (« Mes logements »), le bouton qui ouvre le menu des actions
est une icône « trois petits points » (horizontaux), sans texte ni bordure, à droite. Son libellé
d'accessibilité reste « Actions <titre> ».

## Motif

Demande de l'humain du 2026-11-21 : « mes logements list actions remplacer par icône 3 petits
points ». Points horizontaux, sans bordure : décidé seul.
