# Cartes : le message juste après la ligne du nom

- **Date** : 2026-11-22
- **Type** : décision
- **Décidé par** : l'humain (« mettre le message après la ligne du nom du membre »)

## Décision

Sur une carte de « Demandes reçues », le dernier message cité vient juste après la ligne du nom du membre (et de
sa date), avant le type de demande et les dates, puis le total.

## Portée

App : `ProfileListScreen` — vaut pour toute carte qui cite un message (aujourd'hui « Demandes reçues »).
