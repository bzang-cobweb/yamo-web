# Le texte d'une demande : « Demande de location … du … pour … personnes »

- **Date** : 2026-11-20
- **Type** : décision
- **Statut** : active
- **Remplace** : 2026-11-20-texte-sans-verbe.md (pour le texte de la demande envoyée)

## Décision

Le texte d'une demande sans le nom de qui la fait (`offer::booking.notify.requested.summary*`,
cartes de la liste et du calendrier) :

- un séjour : « Demande de location « Studio » du 5 déc. 2026 au 7 déc. 2026 pour
  2 personnes. » (`summary_stay`) ;
- une visite : « Demande de visite « Maison » le 28 nov. 2026. » (`summary`) — décidé seul,
  une visite n'ayant pas de personnes.

En anglais « Rental request for “…” from … to … for 2 people. », « Visit request for “…” on
… » ; en allemand « Mietanfrage für „…“ vom … bis … für 2 Personen. », « Besichtigungsanfrage
für „…“ am … ».

## Motif

Demande de l'humain du 2026-11-20 : « pour le summary des notifications pour la demande
mettre "Demande de location xxxx du xxxxxx pour xx personnes" ».
