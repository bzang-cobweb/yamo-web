# `2026-11-26` — Modifier et annuler une demande : le type dans le titre

Complète : 2026-11-23-modifier-annuler-comme-accepter.md, 2026-11-26-titres-type-de-demande.md

- **Type** : décision
- **Question posée** : « Mettre modifier la demande de visite ou de séjour et pareil pour annuler ».
- **Ce qui est retenu** : le titre de navigation des formulaires de modification et d'annulation nomme le type de la demande : « Modifier la demande de séjour » / « de visite », « Annuler la demande de séjour » / « de visite ». En anglais « Edit the stay request », « Cancel the visit request » ; en allemand « Aufenthaltsanfrage ändern », « Besichtigungsanfrage stornieren ». C'est le titre du panneau ouvert depuis la page de la demande.
- **Comment** : le même libellé que les titres des notifications (`BookingNotification::requestLabel`, `:request`) ; sans demande connue, « Modifier la demande ».
- **Motif** : comme les titres des notifications, le formulaire dit de quelle demande il s'agit.
- **Tranché par** : humain
