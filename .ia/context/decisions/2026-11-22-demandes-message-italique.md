# Cartes : le message en italique, sans citation

- **Date** : 2026-11-22
- **Type** : décision
- **Décidé par** : l'humain (« enlever la quote sur le message et le mettre simplement en italique »)

## Décision

Sur les cartes des listes du profil (aujourd'hui « Demandes reçues »), le message n'est plus dans un bloc de
citation : il s'affiche simplement en italique, en petit, sur une ligne, puis « … ».

## Portée

App : `ProfileListScreen`. Les citations des notifications ne changent pas.
