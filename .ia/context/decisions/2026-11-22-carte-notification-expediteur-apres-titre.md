# Carte de notification : l'expéditeur juste après le type

- **Date** : 2026-11-22
- **Type** : décision
- **Demandé par** : l'humain (« notifications cards déplacer l'expéditeur après le titre »)
- **Complète** : 2026-11-22-carte-notification-texte.md

## Décision
Sur la carte, de haut en bas :
1. le type ;
2. le nom de qui envoie (en lien, sauf si c'est nous) ;
3. le texte de la notification ;
4. le message ;
5. la date.

Quand le nom est affiché, le texte reste celui sans le nom.

## Portée
`NotificationsScreen` (app).
