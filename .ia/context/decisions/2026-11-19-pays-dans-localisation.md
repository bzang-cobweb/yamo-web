# `2026-11-19` — Back-office d'une offre : le pays dans « Localisation »

- **Type** : décision
- **Question posée** : « déplacer le pays dans le tab localisation en backoffice ».
- **Réponse** : la demande elle-même.
- **Ce qui est retenu** : le pays de l'offre quitte « Annonce » pour la tête de l'onglet « Localisation », avant l'adresse (dont il filtre les choix). L'onglet est désormais toujours affiché ; l'adresse et son indication seulement pour un domaine qui a une adresse.
- **Motif** : la demande de l'humain.
- **Portée** : `OfferForm` du back-office (module Offer).
- **Corollaires** : aucun changement de données ni d'API.
- **Tranché par** : humain
