- **Type** : décision
- **Question posée** : « dans détail d'une demande ajouter la ville sur le titre composé ».

- **Ce qui est retenu** : sous le nom du logement, le titre composé reprend la ligne du type du domaine, ville comprise (« Location meublée · Studio · Douala »), la même que sur la fiche de l'offre et les cartes.
- **Motif** : la demande de l'humain.
- **Portée** : `BookingResource::composed_title`.
- **Corollaires** : l'app affiche la valeur servie, sans changement.
- **Tranché par** : humain
