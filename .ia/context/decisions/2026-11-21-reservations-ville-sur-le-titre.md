# « Mes réservations » : la ville au bout du titre

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active
- **Complète** : 2026-11-21-reservations-titres-inverses-sans-prix.md

## Décision
Sur une carte de « Mes réservations », la ville n'a plus sa propre ligne : elle termine le titre,
« Studio meublé à Bonanjo · Douala ». Dessous : « Location meublée · Studio », puis le type de
demande et les dates. Sans adresse, le titre reste le titre saisi.

## Motif
Demande de l'humain du 2026-11-21 : « remettre la ville sur le titre ».
