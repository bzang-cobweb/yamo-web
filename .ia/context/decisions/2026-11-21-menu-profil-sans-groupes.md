# Menu du profil : une seule liste, sans titres de groupe

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active
- **Remplace en partie** : 2026-11-19-contrat-reservations-logements-profil.md (l'affichage en groupes titrés)

## Décision

Dans l'app, le menu du profil est une seule liste de liens, sans les titres « Compte »,
« Voyageur », « Hôte ». L'ordre reste celui servi par le serveur (liens du compte, puis du
voyageur, puis de l'hôte).

## Motif

Demande de l'humain du 2026-11-21 : « annuler la séparation des liens du menu dans profil ».
Retrait côté app seulement : le serveur sert encore le groupe de chaque lien (`group`), qui
fixe l'ordre — décidé seul.
