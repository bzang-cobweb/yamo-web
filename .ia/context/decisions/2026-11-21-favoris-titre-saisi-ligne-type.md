# Favoris : titre saisi, ligne du type dessous

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active
- **Complète** : 2026-11-21-cartes-titre-saisi-ligne-type.md

## Décision
Les cartes de « Mes favoris » prennent le titre et le type des cartes de l'accueil, via
`OfferCardTitle::of()` :
- le titre est le titre saisi ;
- dessous, « Location meublée · Studio · Douala ».

Le cœur plein, la note et le prix ne changent pas.

## Motif
Après la question « l'appliquer aussi aux cartes des favoris ? », réponse de l'humain du
2026-11-21 : « ajouter favoris sur les cards de l'accueil ». Lue comme : les favoris comme les
cartes de l'accueil.
