# Carte de notification : sans photo, le nom avant le message, la date à droite

- **Type** : décision de conception
- **Date** : 2026-11-20
- **Décidé par** : l'humain (« déplacer le nom de l'utilisateur de la card notification ; mettre le nom avant son message et mettre la date après le message aligné à droite » ; « enlever la photo »)
- **Complète** : 2026-11-20-type-et-statut.md ; remplace, pour la carte de la liste, l'en-tête photo-nom-date de 2026-11-19-carte-notification

## Décision

Sur la carte d'une notification, dans la liste, de haut en bas :
1. le type en gras, et dessous le statut réel de la demande ;
2. le texte, sans le nom de qui agit ;
3. le nom de qui agit (sans lien), puis son message sur une ligne ;
4. la date, alignée à droite.

Plus de photo sur la carte (ni le cercle vert « en ligne »).

## Portée

La page d'une notification et les cartes du calendrier gardent leur en-tête (photo, nom).
