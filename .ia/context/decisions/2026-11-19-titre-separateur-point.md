# `2026-11-19` — Titre d'item de logement : séparateur « · »

- **Remplace** : `2026-11-19-titre-tirets-avis.md`, pour le séparateur du titre seulement.
- **Type** : décision
- **Question posée** : demande directe : « utilise le même séparateur au lieu du tiret ».
- **Réponse** : la demande.
- **Ce qui est retenu** : le titre d'un logement se lit « Studio · meublé · Douala », avec le même séparateur « · » que la ligne en gras (« 3 chambres · 60 000 FCFA / jour »). Une partie absente disparaît avec son séparateur.
- **Motif** : un seul séparateur dans l'item.
- **Portée** : `RentalDomain::itemTitle`.
- **Corollaires** : aucun.
- **Tranché par** : humain
