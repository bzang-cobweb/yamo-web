# « Mes réservations » : sans le nombre de personnes sur les cartes

- **Date** : 2026-11-21
- **Type** : décision
- **Statut** : active
- **Complète** : 2026-11-21-reservations-type-de-location-titre.md

## Décision
Sur une carte de « Mes réservations », la ligne des dates n'affiche plus le nombre de personnes
(« 2 personnes ») : seulement le type de demande et les dates.

## Motif
Demande de l'humain du 2026-11-21 : « enlever le nombre de personne ».

## Portée
Les cartes de « Mes réservations » seulement. Les cartes de « Réservations reçues » et la page
d'une demande (résumé, lignes) le gardent.
