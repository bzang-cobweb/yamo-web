# `2026-11-23` — Modifier et annuler une demande : la même tête que « Accepter la demande »

- **Type** : décision
- **Question posée** : « le titre composé apparait comme titre et le titre de l'offre n'apparaît même pas. ce doit être la même chose que sur le formulaire accepter la demande ».
- **Réponse** : la demande elle-même.
- **Ce qui est retenu** :
  - barre du haut : « Modifier la demande » / « Annuler la demande » (`navigationTitle`) ;
  - titre : le titre saisi du logement (à défaut, l'action) ;
  - sous-titre : le titre composé, ville comprise ;
  - titre et sous-titre centrés.
- **Motif** : la demande de l'humain.
- **Portée** : `BookingEditForm`, `BookingCancelForm`.
- **Corollaires** : aucun changement dans l'app.
- **Tranché par** : humain
