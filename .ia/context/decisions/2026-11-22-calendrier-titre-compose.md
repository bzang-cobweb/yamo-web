# Calendrier d'un logement : le titre composé sous le titre

- **Date** : 2026-11-22
- **Type** : décision
- **Demandé par** : l'humain (« dans la page calendrier mettre le titre composé après le titre »)

## Décision

En tête du calendrier d'un logement : le titre saisi, puis le titre composé (« Location meublée · Studio · Douala »), centré, en gris, puis l'adresse et l'indication, comme sur la fiche.

## Portée

`OfferCalendar::month` sert `composed_title`. Mobile : `OfferCalendarScreen`.
