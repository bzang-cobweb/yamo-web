# `2026-11-26` — Le formulaire « Envoyer un message » sans le titre de l'offre

- **Type** : décision
- **Question posée** : « enlever le titre de l'offre dans le formulaire envoyer message ».
- **Ce qui est retenu** : le formulaire `offer.message` n'a plus le titre de l'offre en sous-titre. Pour la réponse de l'éditeur, le sous-titre est seulement le prénom du membre à qui elle va ; sinon, pas de sous-titre.
- **Tranché par** : humain
