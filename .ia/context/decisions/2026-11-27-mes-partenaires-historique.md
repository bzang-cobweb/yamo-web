# `2026-11-27` — « Mes partenaires » : « Historique » dans le menu d'une carte

Complète : 2026-11-24-mes-partenaires-cartes.md

- **Type** : décision
- **Question posée** : « mes partenaires dropdown menu ajouter un bouton historiques qui dirige vers le détail de la notification du partenaire ».
- **Ce qui est retenu** : le menu ⋮ d'une carte de « Mes partenaires » propose « Historique » (en : « History », de : « Verlauf »), qui ouvre la page de la dernière notification que le compte voit dans le fil du partenaire (`partner:group:{id}`) : la conversation de ce qui lui est arrivé. Sans fil, pas de bouton. Les liens de la page sont chargés en une requête.
- **Tranché par** : humain
